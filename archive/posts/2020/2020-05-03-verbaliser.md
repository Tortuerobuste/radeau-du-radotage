# Verbaliser

Oh! pour ce qui est de « verbaliser »  
Ils excellent  
Ils excellent  
Pour ce qui est de « verbaliser »  
Ils savent bien emballer.

Dans des mensonges éhontés  
Pour les masques  
Pour les masques  
Des mensonges à la volée  
Pour tenter de nous tromper.

Chercher à nous faire croire  
Que les tests  
Que les tests  
Que tester donne déboires  
C’est encore pour nous cacher

Qu’ils préfèrent ne pas savoir:  
« Flics, allez!  
Foncez! Foncez!  
Allez dont leur faire voir  
Que nous savons verbaliser »

Pour le verbal policier  
Pas d’problème!  
Pas d’problème!  
Ils savent nous faire suer!
