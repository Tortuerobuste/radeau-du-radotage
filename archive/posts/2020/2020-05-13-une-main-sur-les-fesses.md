# Une main sur les fesses?

Mais oui! C’était une douce caresse,  
Ordinaire dans sa jeunesse,  
Les femmes en étaient honorées!  
Las! Les choses ont bien changé!  
Il prétend même qu’une princesse  
Soupirait pour ses caresses.  
Tant de filles formatées  
A l’attente du prince charmant!  
Qui, pour le premier baiser,  
Attendaient le cœur béant!  
Tant de promotions canapés,  
Naturellement recherchées!  
Tant de jeunes journalistes,  
Prêtes à se prostituer  
Pour être sur la bonne liste  
Des confidentes préférées.  
Tant de parents honorés,  
Sans chercher la moindre vétille,  
De voir un puissant se pencher  
Sur les appâts de leur fille.  
Quitte à dénoncer plus tard!
