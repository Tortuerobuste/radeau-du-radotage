# Géniale, mon idée…Non?

Pour la nature protéger  
Pour l’eau économiser  
Toilettes sèches adoptées,  
Mais le papier?  
Mais le papier?  
Ca pollue trop le papier  
Sur chaque balcon cultiver  
Un bon nombre de poirées:  
Les feuilles indiféremment  
Serviraient à s’essuyer  
Ou dans la soupe du moment.  
Avantage incontestable  
Les côtes blanchies cuisinées  
Feraient des plats consommables  
Sans grande difficulté.
