# Jeu de potaches

Parmi les jeux de potaches  
Au temps ancien de l’internat  
Pour le pion qui toujours se fâche  
Nous avions trouvé ce jeu-là  
Entre les portes de permanence  
Lâcher une poignée de hannetons  
Qui dans l’absolu silence  
Joueraient un air de mirliton.  
Fallait le voir, le surveillant  
A chercher en vain l’occasion  
Ce farceur, cet insolent  
Producteur de cette perturbation  
De le coller le dimanche!  
Mais tous étaient très occupés  
Rien dans la poche, ni dans la manche  
Dans leurs devoirs accumulés…  
C’était une vraie jouissance  
De mesurer son impuissance!
