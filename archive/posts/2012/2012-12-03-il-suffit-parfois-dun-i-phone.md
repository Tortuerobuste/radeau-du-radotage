# Il suffit parfois d’un i phone

Le temps était à tempête  
Grosses bourrasques virulentes  
Pluie diluvienne sur les têtes  
Arbres cassés, branches volantes.  
Pour échapper à son sadique  
Qui voulait la terroriser  
Elle cherchait dans la panique  
Un moyen d’être protégée.  
Il suffit parfois d’un i phone  
Prêté le temps d’un message  
Il suffit parfois d’un i phone  
Pour échapper à une cage !
