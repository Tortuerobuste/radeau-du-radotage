# Pour qui je voterai?

Je voterai pour…  
Les déesses  
Qui me font rêver d’amour  
Pour leurs petits mots de tendresse  
Qui ensoleillent mon chemin  
Pour leurs regards malicieux  
Qui font encore croire à demain  
Alors ma foi que je suis vieux !
