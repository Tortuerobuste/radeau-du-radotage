# Tôt le matin

Ce matin , juste levé,  
J’étais dans la cuisine,  
Encore en slip, j’entends frapper…  
C’était la jeune voisine  
Avec son petit bébé.  
Elle cherchait non des baisers,  
Mais venait vite m’alerter  
Que mes ânes s’étaient sauvés…  
Hop! Sauter dans le pantalon  
Pour aller les rechercher…  
Un licol, une carotte, allons!  
Je les trouve bien paisibles  
A brouter entre les noyers  
Pour une fois c’est possible  
Le licou de leur passer.  
Me voilà avec ma suite  
Clopin-clopant pour rentrer  
Mais pour éviter les fuites  
Il faut partout vérifier.  
Les chiens des chasseurs  
Les chevreuils ont affolé  
Dans le désarroi, la peur  
Les fils du parc ont forcé…  
Voilà le vieux débris  
Par la recherche fatigué  
Obligé de réparer les bris  
De relever les clôtures …Oh! Gai!…
