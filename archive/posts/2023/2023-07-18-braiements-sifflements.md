# Braiements, sifflements…

Les ânes braient,  leurs crottins  
Peuvent fertiliser le jardin  
Les scarabées de leurs excréments  
Se font tartines évidemment…  
Quand sifflent les serpents  
Toutes les buses,  
De leur venin s’amusent  
Innocemment…?
