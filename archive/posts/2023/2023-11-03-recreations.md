# Récréations

Les autres garçons jouaient aux billes…  
Moi je préférais les jeux d’aiguilles.  
Je tricotais avec les filles.  
Mon Dieu que je les aimais!  
La plus grande, Odette s’appelait.  
Quand je perdais une maille,  
Elle se penchait vaille que vaille  
Pour remettre le tout en état.  
Les autres jouaient au ballon  
Jeux que je n’aimais pas:  
Les coups de pied, les gnons,  
Je préférais les jeux d’aiguilles.  
Je tricotais avec les filles.
