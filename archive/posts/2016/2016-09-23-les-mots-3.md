# Les mots

Les mots, je les décris  
Je les écris  
Je les crie.  
Sont parfois une brise  
Exquise,  
Une bise  
C’est souvent  
Un torrent  
Violent  
Une épée  
Acérée  
Pointée  
Un volcan  
Explosant  
Incandescent  
Une lave  
Qui bave  
Qui brave  
Une caresse  
Tendresse
