# Le jeu de cache carotte

Quand j’arrive le matin  
Pour nourrir mes lapins  
Les petits se ruent vers moi  
Pour me dire: « Tu as quoi? »  
Pendant que, vers eux, je glisse  
Une belle poignée de foin  
Je vais cacher en coulisse  
Des carottes dans un coin.  
Il faut toujours un moment,  
Eloigné par les plus grands,  
Suite à une chasse maline  
Pour que le plus jeune nain  
Tout petit mais très malin  
Trouve la jaune racine.
