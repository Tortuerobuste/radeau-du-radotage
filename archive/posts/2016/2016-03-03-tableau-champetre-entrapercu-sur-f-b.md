# Tableau champêtre (entr’aperçu sur F B)

Elles ont posé leurs bicyclettes  
Pour s’ébattre dans le pré  
Ce sont trois jolies nymphettes  
En balade pour une journée.  
Elles admirent les pâquerettes  
Les tussilages veloutés  
Suivent les petites bêtes  
Pour découvrir leur terrier.  
Formant un rond de sorcière  
Ont poussé des mousserons  
Les cueillent en douce manière  
Omelette dégusteront.  
Bien caché derrière une branche  
On devine un écureuil  
Qui, la tête, doucement penche  
Pour les surveiller d’un oeil.  
Le soleil à l’horizon  
Les bénit à sa façon.  
Un tableau plein de douceur  
A vous réjouir le coeur.
