# Neige d’avril

Neige d’avril calamité  
Branches  cassées  
Horreur

Le magnolia désemparé  
Ses pétales éparpillés  
Malheur.

Plates-bandes dévastées  
Mais où donc sont passées  
Les fleurs?

Les petits nids dans le fourré  
Trop secoués sont tombés  
Pleur!

Les chevreuils gourmands  
Ont le dessert permanent  
A leur hauteur!
