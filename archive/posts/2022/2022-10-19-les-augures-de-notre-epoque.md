# Les augures de notre époque

Il fut un temps, dans les ténèbres  
De la haute antiquité,  
Où les rois, les combattants célèbres  
Demandaient aux augures vérité.  
Foin de ces vieilles fariboles  
Les flamants roses qui s’envolent  
N’annoncent victoire pour personne  
Et si votre chat ronronne  
Ce n’est point pour vous annoncer  
Que, jour de chance, il faut foncer.  
Mais voilà que la nouvelle mode  
Pour annoncer Armageddon  
Est de donner aux vers un code  
Pour les distinguer nom de nom!  
Si les lombrics sont en grève  
Pire que pour les raffineurs  
C’est que la planète crève  
Préparez-vous au malheur!
