Pour qui je voterai (3)

2012-05-05 · Non classé

Je voterai pour les mères

Encore béantes de gésine

Reposant leur chevelure

Moite jusqu’à la racine

Sur le lit aussi blanc

Que leur visage épuisé

Mais rayonnant

De félicité
