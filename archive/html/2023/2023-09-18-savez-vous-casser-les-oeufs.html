Savez-vous casser les oeufs?

2023-09-18 · Non classé

 

 (quand avec le panier d’oeufs on s’emmêle les pinceaux au milieu de la grande salle)

 

Savez-vous casser les oeufs?

A la mode,

A la mode

Savez-vous casser les oeufs?

A la mode de JOJO

 

On les casse avec les côtes

Pour servir les internautes

 

On les casse avec les genoux

En criant : »coucou! coucou! »

 

On les casse dans son chapeau

Pour les rendre un peu plus gros

 

On les casse sous le buffet

Pour un futur festin secret

 

On les casse dans les chaussures:

Bon cirage, je vous assure

 

On les casse dans la cheminée

En omelette calaminée

 

Mais pas dans la casserole

C’est quand même pas pigeon vole!
